# Stand CEVET · ISI CONECTA

Sitio estático del stand de CEVET (Centro de Viajes Tecnológicos, UTN FRT) en ISI CONECTA, 19/11/2026: la guía para el equipo (`guia.html`), la pantalla en loop con fotos de Frankfurt 2026 (`kiosco.html`) y los juegos (ruleta y nombre en binario). No usa internet ni build: para usarlo sin conexión, descargá o copiá la carpeta y hacé doble clic en `index.html`. También se publica tal cual en GitHub Pages.
